# LocalRNC

API RestFULL to communicate with the DGII and offer to consult a RNC locally

## 🚀 Features

- Find companies by RNC
- Manage new companies
- Synchronization with DGII

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/angelpimentell/LocalRNC.git
cd LocalRNC

PM > Update-Database
```
